Escanea el QR del e-ticket desde tu celular.

Listo para escanear Activa la cámara y apunta al código QR.

¿Cómo funciona?

  1. Abre esta página desde el celular del encargado.
  2. Pulsa Activar cámara y acepta el permiso.
  3. Apunta al QR del e-ticket.
  4. El sistema mostrará si es válido, usado o desconocido.

Esta es una demo local. Para una fiesta real con varios celulares, hace falta conectar una base de datos online.
